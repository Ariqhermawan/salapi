# Port a claude.ai/design Export into Salapi

Import a page generated by **claude.ai/design** (a landing page, marketing
page, or any standalone HTML export) into the Salapi web app, served as a
**static** page from `web/public/<dest>/index.html`.

A raw claude.ai/design export is NOT production-safe as-is. It ships with a
hidden developer "Tweaks panel" — DEAD and NOISY in production. This skill
sanitizes it, wires the CSP, copies assets, render-verifies, and ships.

This is a project runbook. Repo root in this environment:
`C:\Users\Lenovo\OneDrive\Documents\Claude\Projects\Hackathon`. The web app is
under `web/`. Use absolute paths.

## When to Use

- The user hands you a claude.ai/design export (a `.html` file, or a `.tar.gz`
  / `.zip` design archive) and wants it live in the Salapi app.
- "Port this design", "import this landing page", "ship this design export",
  "add this generated page to the app", "drop this under /landing".

## When NOT to Use

- Building a real Next.js route/component (use the React app under `web/src/`).
  This skill is for STATIC, self-contained exported pages only.
- A design that needs live app data, auth, or server logic — that is not a
  static page; build it as a route instead.

## THE BUG THIS PREVENTS (read this first)

A claude.ai/design HTML export embeds a hidden dev **Tweaks panel**. In
practice it is some combination of:

1. A mount point: `<div id="tweaks-root"></div>` (usually empty — React fills it
   at runtime; occasionally pre-rendered with nested `<div>`s).
2. React loaded from **outside the app** — in ANY of these shapes:
   - classic CDN `<script src>` dev builds, e.g.
     `react.development.js` / `react-dom.development.js` from
     `unpkg.com` / `jsdelivr` / `cdnjs` / `esm.sh` / `skypack`, plus a Babel
     standalone script;
   - a `<script type="importmap">` pinning `react`/`react-dom` to a CDN URL;
   - a `<script type="module">` that does
     `import { createRoot } from "https://esm.sh/react-dom@18/client"` — **note
     this has NO `src` attribute**, so a naive "remove external src" pass misses
     it.
3. A trailing **inline** `<script>` (often `type="text/babel"`) containing raw
   **JSX** — `TweaksPanel`, `useTweaks`, `applyTweaks`, `TWEAK_DEFAULTS`, and a
   `ReactDOM.createRoot(...).render(<App/>)` (or `createRoot(...).render(...)`).
4. A `<template id="__bundler_thumbnail">…</template>` block.

In Salapi production all of this is **dead and noisy**:

- The CDN scripts, importmap, and `type="module"` CDN imports are **blocked by
  the app CSP** (`script-src 'self' 'unsafe-inline'`, `connect-src` does not list
  `esm.sh`/`unpkg`/etc.). They never load.
- A `type="text/babel"` or raw-JSX inline script is **not valid JS**; the browser
  either ignores it (no Babel) or throws an uncaught `SyntaxError` on every load.

So the Tweaks panel does nothing except spam CSP violations and JS errors. It
must be **completely stripped**.

What you KEEP: legitimate **self-contained inline vanilla-JS** scripts the page
actually needs — they have no external deps and run fine under
`script-src 'self' 'unsafe-inline'`. In the shipped landing page these are:
- the **sticky-nav** handler (`var nav = document.getElementById('nav'); ... onScroll`),
- the **IntersectionObserver scroll-reveal**,
- the **`<canvas>` "flowing-money ribbon"** animation.

> Note on the live file: `web/public/landing/index.html` still contains the
> harmless `<template id="__bundler_thumbnail">` (it predates step 4 of this
> runbook). It is inert, but new ports should remove it per step 2.

Rule of thumb — **classify by script TYPE and call signature, NOT by the
presence of a capitalized tag.** KILL a script if it: has an external `src`;
has `type` of `module` / `text/babel` / `importmap`; imports from a URL; or calls
`createRoot` / `ReactDOM` / `hydrateRoot` / `React.createElement` / `render(<…`.
KEEP inline scripts that are plain DOM/canvas JS — even if they build an HTML
string like `'<Icon/>'` or mention a `<Component/>` in a comment.

## Procedure

### 1. Locate the export and its assets

The export usually arrives as a project archive (often `.tar.gz`, sometimes
`.zip`). Extract it and find the landing `.html` plus the asset folder it
references (in the shipped case: `salapi-v15/img/*.png` + `salapi-v15/flags/*.svg`).

```powershell
# extract (tar ships with Windows 10+)
New-Item -ItemType Directory -Force C:\tmp\design-export | Out-Null
tar -xzf "C:\path\to\export.tar.gz" -C C:\tmp\design-export
```

Then find the HTML and the referenced asset prefix:

- Find the HTML: Glob `**/*.html` under the extracted dir; the landing page is
  the large one (the shipped one is ~1250 lines).
- Find the asset prefix it uses: the HTML references assets by a **relative**
  path that sits beside it, e.g. `salapi-v15/img/home.png`,
  `salapi-v15/flags/ph.svg`. Grep for it:

```
Grep  pattern: (src|href)=["'][^"':]+\.(png|jpe?g|svg|webp|avif|gif)
      path: <the .html>   output_mode: content   -n: true
```

Note the common prefix (e.g. `salapi-v15/`) — you preserve it verbatim in step 4
so the HTML's relative URLs keep resolving.

### 2. Sanitize the HTML

Decide the destination first (the shipped one is `dest = landing`). Then run the
sanitizer below. It removes, in order:

1. the `<div id="tweaks-root">…</div>` mount (depth-aware, so nested `<div>`s in
   a populated panel don't truncate the match and leave orphan tags),
2. any external `<script src>` (named CDN, protocol-relative `//host`, absolute
   cross-origin) and any babel `<script src>`,
3. any inline `<script>` that is NOT plain vanilla JS — i.e. `type` is
   `module` / `text/babel` / `importmap`, OR the body imports from a URL, OR it
   references `ReactDOM` / `hydrateRoot` / `createRoot(` / `React.createElement` /
   `render(<…` / the tweaks symbols,
4. the `<template id="__bundler_thumbnail">` block (scoped by id — legit page
   `<template>`s are preserved).

It KEEPS every inline `<script>` that is plain vanilla JS — sticky-nav,
IntersectionObserver, the canvas ribbon — even if it builds an HTML string with a
capitalized tag or mentions a component in a comment.

Write it to a throwaway file and run with node (works from the repo root):

```js
// sanitize-design.js  —  node sanitize-design.js <in.html> <out.html>
const fs = require("fs");
const [, , inPath, outPath] = process.argv;
if (!inPath || !outPath) { console.error("usage: node sanitize-design.js <in.html> <out.html>"); process.exit(1); }
let html = fs.readFileSync(inPath, "utf8");
const countSrc = (h) => (h.match(/<script\b[^>]*\bsrc=/gi) || []).length;
const before = countSrc(html);

// 1. Remove the tweaks mount point — depth-aware so nested <div>s in a populated
//    panel don't truncate the match and leave orphan </div> tags behind.
function removeTweaksRoot(s) {
  const open = /<div\b[^>]*\bid=["']tweaks-root["'][^>]*?(\/?)>/i;
  let m;
  while ((m = open.exec(s))) {
    const start = m.index;
    if (m[1] === "/") { s = s.slice(0, start) + s.slice(start + m[0].length); continue; } // self-closing
    let depth = 1; const re = /<\/?div\b[^>]*>/gi; re.lastIndex = start + m[0].length;
    let t, end = -1;
    while ((t = re.exec(s))) { depth += t[0][1] === "/" ? -1 : 1; if (depth === 0) { end = t.index + t[0].length; break; } }
    s = end === -1 ? s.slice(0, start) + s.slice(start + m[0].length)  // unbalanced: drop open tag only
                   : s.slice(0, start) + s.slice(end);                  // splice whole subtree
  }
  return s;
}
html = removeTweaksRoot(html);

// 2. Remove ANY external <script src> (named CDN, protocol-relative, absolute
//    cross-origin) and anything loading babel.
html = html.replace(/<script\b[^>]*\bsrc=["']\s*(?:https?:)?\/\/[^"']*["'][^>]*>\s*<\/script>/gi, "");
html = html.replace(/<script\b[^>]*\bsrc=["'][^"']*babel[^"']*["'][^>]*>\s*<\/script>/gi, "");

// 3. Inline scripts: drop anything that is NOT plain vanilla JS.
html = html.replace(/<script\b([^>]*)>([\s\S]*?)<\/script>/gi, (full, attrs, body) => {
  if (/\bsrc=/i.test(attrs)) return full; // external src already handled above
  if (/\btype=["'](?:text\/babel|module|importmap)["']/i.test(attrs)) return ""; // non-vanilla type
  const bad =
    /\b(TweaksPanel|useTweaks|applyTweaks|TWEAK_DEFAULTS|ReactDOM|hydrateRoot)\b/.test(body) ||
    /\bReact\s*\.\s*(createElement|createRoot)\b/.test(body) ||
    /\bcreateRoot\s*\(/.test(body) ||
    /\bimport\b[^;]*\bfrom\s*["'](?:https?:)?\/\//.test(body) ||   // ESM import from a URL
    /\brender\s*\(\s*</.test(body);                                // render(<App …
  return bad ? "" : full;                                          // keep legit vanilla JS
});

// 4. Remove the bundler thumbnail <template> (scoped by id; other templates kept).
html = html.replace(/<template\b[^>]*\bid=["']__bundler_thumbnail["'][^>]*>[\s\S]*?<\/template>/gi, "");

fs.writeFileSync(outPath, html);
console.log("sanitized:", inPath, "->", outPath);
console.log("external <script src> tags:", before, "->", countSrc(html));
```

> Heuristic notes (why this shape): classifying by capitalized-tag presence
> falsely strips legit vanilla scripts that build HTML strings (`'<Icon/>'`) or
> mention components in comments. This version classifies by the script's `type`
> attribute and by React-runtime call signatures + URL imports instead, which is
> both stricter on dead code (catches `type="module"`/`importmap`/`text/babel`
> and bare `createRoot(`) and safe for string/comment false-triggers. If a legit
> inline script is ever removed, eyeball it — but in practice the only non-vanilla
> inline script in these exports is the Tweaks panel.

### 3. Verify ZERO dead code remains

Run these against the SANITIZED file. All must be empty/zero before you proceed.
Use the Grep tool (or rg) — these are the explicit gate checks:

```
# (a) NO external / protocol-relative <script src> — must return NOTHING
Grep  pattern: <script[^>]*src=["'](https?:)?//   path: <out.html>  output_mode: content
Grep  pattern: <script[^>]*src=["'][^"']*(unpkg|jsdelivr|cdnjs|esm\.sh|skypack|babel)  path: <out.html>  output_mode: content

# (b) NO non-vanilla inline script type — must return NOTHING
Grep  pattern: <script[^>]*type=["'](module|text/babel|importmap)["']   path: <out.html>  output_mode: content

# (c) NO URL ESM import left behind — must return NOTHING
Grep  pattern: import[^;]*from\s*["'](https?:)?//   path: <out.html>  output_mode: content

# (d) NO tweaks / React-runtime symbols — must return NOTHING
Grep  pattern: tweaks-root|TweaksPanel|useTweaks|applyTweaks|TWEAK_DEFAULTS|ReactDOM|hydrateRoot   path: <out.html>  output_mode: content

# (e) NO JSX render / mount call — must return NOTHING
Grep  pattern: createRoot\(|render\(\s*<|<App\s*/>   path: <out.html>  output_mode: content
```

Quick one-shot node assertion (exits non-zero if anything remains). Save it as
`assert-clean.js` and run `node assert-clean.js <out.html>` (it reads
`process.argv[2]`, i.e. the file path you pass):

```js
// assert-clean.js  —  node assert-clean.js <out.html>
const s = require("fs").readFileSync(process.argv[2], "utf8");
const bad = [
  [/<script[^>]*src=["'](https?:)?\/\//i, "external <script src>"],
  [/<script[^>]*type=["'](module|text\/babel|importmap)["']/i, "non-vanilla script type"],
  [/import[^;]*from\s*["'](https?:)?\/\//i, "URL ESM import"],
  [/\b(tweaks-root|TweaksPanel|useTweaks|applyTweaks|TWEAK_DEFAULTS|ReactDOM|hydrateRoot)\b/, "tweaks/React symbol"],
  [/createRoot\(|render\(\s*<|<App\s*\/>/, "JSX render/mount call"],
].filter(([re]) => re.test(s));
if (bad.length) { console.error("FAIL — still present:", bad.map((b) => b[1]).join(", ")); process.exit(1); }
console.log("OK — clean. inline vanilla scripts kept:",
  (s.match(/<script\b(?![^>]*\bsrc=)(?![^>]*type=["'](?:module|text\/babel|importmap))/gi) || []).length);
```

```powershell
node C:\tmp\assert-clean.js "C:\path\to\out.html"
```

If any check fails, go back to step 2 — do not proceed.

### 4. Copy assets + write the HTML into the public folder

Preserve the relative asset prefix the HTML uses (e.g. `salapi-v15/`) so the
embedded `src="salapi-v15/img/..."` URLs resolve. Destination layout for
`dest = landing`:

```
web/public/landing/
  index.html                 <- the sanitized HTML
  salapi-v15/img/*.png        <- copied, same relative path the HTML references
  salapi-v15/flags/*.svg
```

```powershell
$dest = "landing"   # change per import
$pub  = "C:\Users\Lenovo\OneDrive\Documents\Claude\Projects\Hackathon\web\public\$dest"
New-Item -ItemType Directory -Force $pub | Out-Null
# copy the asset folder preserving its prefix (e.g. salapi-v15\)
Copy-Item -Recurse -Force "C:\tmp\design-export\<...>\salapi-v15" "$pub\salapi-v15"
# write the sanitized HTML as index.html
Copy-Item -Force "C:\path\to\out.html" "$pub\index.html"
```

Confirm: `index.html` sits at `web/public/<dest>/index.html`, and every asset
the HTML references exists at `web/public/<dest>/<same-relative-path>`. Spot-check
by grepping the sanitized HTML for asset paths and verifying each file exists.

### 5. CSP — allow what the page legitimately uses

Read `web/next.config.ts`. The CSP is the `csp` array of directives.

- **External scripts:** none must remain (step 3 guaranteed this). Do NOT add a
  CDN to `script-src` and do NOT add `esm.sh`/`unpkg`/etc. to `connect-src` —
  that would re-enable the very thing you stripped. The page must run on
  `script-src 'self' 'unsafe-inline'` only.
- **Google Fonts:** these exports load Geist/Newsreader/etc. from Google Fonts.
  If the HTML references `fonts.googleapis.com` / `fonts.gstatic.com` (grep the
  sanitized file), the CSP must allow them:
  - `style-src` must include `https://fonts.googleapis.com`
  - `font-src` must include `https://fonts.gstatic.com`

  In this repo they are **already present** (added when `/landing` shipped):

```ts
"style-src 'self' 'unsafe-inline' https://fonts.googleapis.com",
"font-src 'self' https://fonts.gstatic.com",
```

  If the page uses a different font/asset host, add only that exact host to the
  matching directive — never widen `script-src` or add a script CDN to
  `connect-src`.

`viewport|full`.



Open the PNG and confirm: **fonts render** (not fallback serif), **images and
flags load** (no broken-image boxes), layout is intact. Also open the page in a
browser and check the **console is clean** — no CSP violations, no `SyntaxError`.
If you see a blocked `unpkg`/`esm.sh`/`react.development.js` request, a blocked
ESM import, or a JSX `SyntaxError`, sanitization missed something — go back to
step 2.

`landing_test.png` is gitignored (`*_test.png` per the browser-automation
convention) — do not commit it.

### 7. Ship

This is a **STATIC** page: Next.js serves anything under `web/public/` verbatim,
so the file at `web/public/<dest>/index.html` is reachable at
`/<dest>/index.html` (e.g. `https://salapi.app/landing/index.html`). There is no
Next route, component, or build step for the page itself.

1. **Build-verify before committing:** `cd web ; npm run build` — must pass.
   (This also confirms the `next.config.ts` CSP edit is valid.)
2. Commit the HTML, the copied asset folder, and any `next.config.ts` CSP change
   together. Conventional commit, e.g.
   `feat(landing): ship V<n> marketing landing at /<dest> (static)`.
3. **Deploy = push to `main`.** Vercel runs `next build` on every push to `main`
   and auto-deploys to the public `salapi.app` alias (confirmed by `.github/
   workflows/ci.yml` and `e2e.yml`). Branch first if you are on `main` and the
   user has not asked to push.
4. After deploy, re-verify the live URL with `shot.js` against
   `https://salapi.app/<dest>/index.html` and confirm a clean console.

## Definition of Done

- [ ] `web/public/<dest>/index.html` exists; assets at their referenced relative paths.
- [ ] ZERO external/protocol-relative `<script src>` in the HTML (step 3 grep empty).
- [ ] ZERO `type="module"` / `type="text/babel"` / `type="importmap"` scripts and ZERO URL ESM imports (step 3 grep empty).
- [ ] ZERO `tweaks-root` / `ReactDOM` / `hydrateRoot` / `createRoot(` / `TweaksPanel` / `render(<…` (step 3 grep empty).
- [ ] Legit inline vanilla-JS scripts (sticky-nav, scroll-reveal, canvas) preserved and working.
- [ ] CSP allows Google Fonts if used; `script-src` NOT widened and no script CDN added to `connect-src`.
- [ ] Render-verify PNG shows fonts + images; browser console is clean (no CSP/JSX errors).
- [ ] `npm run build` passes; shipped via push to `main` (Vercel auto-deploys to salapi.app).
